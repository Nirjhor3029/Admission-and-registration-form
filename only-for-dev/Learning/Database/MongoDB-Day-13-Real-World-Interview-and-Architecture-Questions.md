# MongoDB Day 13 — Real-World Interview and Architecture Questions

This day helps you think like a senior engineer in interviews and architecture discussions.

## 1. Interview-style questions

Be ready to answer:
- When would you embed data instead of reference it?
- What is the difference between a single-field and compound index?
- How would you design a schema for a course enrollment system?
- How would you prevent double booking?
- How would you design payment flow so retries do not create duplicates?

## 2. Architecture questions

Senior engineers think in terms of:
- read patterns
- write patterns
- data growth
- consistency
- cost
- failure handling

## 3. Example design challenge

Design a system for:
- student registration
- payment verification
- course enrollment
- reports

Questions to answer:
- which collections exist?
- what should be embedded?
- what should be referenced?
- where should indexes go?
- what happens if requests retry?

## 4. Study goal for Day 13

Build the habit of reasoning about systems as a whole, not just individual queries.
