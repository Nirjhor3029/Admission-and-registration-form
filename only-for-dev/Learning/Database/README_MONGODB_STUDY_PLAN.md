## Professional Goal

By the end of this path, you should be able to:

- design schemas for real applications
- choose between embedding and referencing
- optimize queries with indexes
- build reporting pipelines with aggregation
- handle correctness with transactions and idempotency
- think about scaling, replication, backups, and security

## How to Use

- Read one file per day.
- Practice the examples manually.
- Revisit earlier files after a few days.
- Use the enterprise handbook as a deeper reference.
- Apply the patterns to your own projects, not just examples.
